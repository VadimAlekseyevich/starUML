6 КОМПИЛЯЦИЯ И СБОРКА СИСТЕМЫ

**6.1. Правила создания системы (приложения)**

В разделе "Компиляция и сборка системы" описывается процесс компиляции и сборки веб-приложения для отладки и инсталляции на вычислительной системе пользователя. Этот раздел также включает в себя описание условий компиляции, включая требования к аппаратному и программному обеспечению.

Для веб-приложения, разработанного на HTML страницах и Java файлах с использованием PostgreSQL в качестве системы управления базами данных, процесс компиляции и сборки включает следующие шаги:

1. Подготовка исходного кода: разработка и поддержка HTML страниц, Java файлов, SQL скриптов для базы данных.

1. Компиляция Java файлов: использование Java компилятора для преобразования исходного кода Java в байт-код Java.

1. Создание и настройка базы данных: выполнение SQL скриптов для создания и настройки базы данных с использованием PostgreSQL.

1. Сборка веб-приложения: интеграция HTML страниц, Java классов и файлов базы данных в рабочее приложение.

1. Тестирование и отладка: проверка функциональности и исправление ошибок в процессе разработки.

Требования к компиляции и сборке системы включают в себя:

- Компьютер с поддержкой Java Development Kit (JDK) для компиляции Java файлов.

- Доступ к PostgreSQL для работы с базой данных.

- Текстовый редактор или интегрированная среда разработки (IDE) для написания и отладки кода.

7 ДОКУМЕНТАЦИЯ

**7.1. Назначение системы и выполняемые функции**

Система предназначена для автоматизации процесса кредитования: от подачи заявки клиентом до рассмотрения и принятия решения сотрудником, с последующим предоставлением клиенту информации о условиях кредита и графике платежей.

**7.2. Условия применения системы**

Для комфортной работы пользователя требуется:

- ОС: Windows 10/11 или Linux (Ubuntu/Debian)

- CPU: от 1.6 GHz

- RAM: от 4 GB

- Разрешение экрана: не ниже 720p

**7.3. Правила инсталляции системы**

- Импортировать проект в IDE для Java.

- Подготовить БД: подключить PostgreSQL напрямую или запустить её в Docker.

- Указать параметры подключения к БД в конфигурации проекта.

- Собрать и запустить приложение локально, затем открыть веб-интерфейс в браузере.
