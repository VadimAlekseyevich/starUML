# Reference — эталон lending

Здесь хранится компактная библиотека эталонов, полученная из исходного `/lending.uml`.

## Зачем это нужно

Исходный файл большой и содержит одновременно модель, визуальные представления, связи, GUID, служебные объекты StarUML и остатки разных стадий проектирования. Повторно анализировать его целиком перед каждой новой диаграммой не нужно.

Для каждого типа схемы здесь фиксируются:

- место элемента в дереве проекта;
- типы StarUML-объектов;
- характерные связи;
- изображение из `Костыль/диаграммы`;
- точный XML-фрагмент из `lending.uml`;
- особенности, которые надо сохранить в нашей работе.

## Важно

Файлы `*.fragment.xml` в `reference/` — **документационные эталоны**, а не самостоятельные StarUML-проекты. Они могут ссылаться на GUID объектов, определённых в других частях `lending.uml`.

Сборочные фрагменты нашего проекта находятся отдельно в `../fragments/`.
