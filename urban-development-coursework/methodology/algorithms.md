# 2. Модель алгоритмов

## Какие UML-диаграммы используем

**[METHOD]** Activity Diagram выделена в методическом обеспечении как лабораторная работа № 12.

**[LENDING]** Эталон содержит 5 Activity Diagram и 4 Statechart Diagram в Logical View.

Поэтому «модель алгоритмов» в нашей рабочей структуре строится прежде всего через **Activity Diagram**, а Statechart используется там, где важен жизненный цикл/состояния объекта.

## Связь с функциональностью

**[LENDING]** Activity Graph `ApplyingForLoan`, `CreditRegistration`, `LoanRepayment` прямо повторяют названия функций/сценариев предметной области.

**[WORKING]** Для каждой Activity Diagram фиксируем `implements_use_case` в реестре. Это предотвращает появление алгоритмов, не связанных с функциональной моделью.

## Гранулярность

Activity Diagram нужна для нетривиального процесса с:

- ветвлениями;
- проверками;
- несколькими ответственными;
- длительными этапами;
- параллельностью;
- существенными объектными потоками.

Простой CRUD-вызов или одно действие не надо искусственно раздувать.

## Первые кандидаты Urban Development

1. **ImportAndValidateData** — загрузка, определение формата/CRS, нормализация, проверка геометрии.
2. **ConfigureScenario** — выбор режима, территории, seed и параметров.
3. **RunGenerationPipeline** — основной конвейер.
4. **CompareScenarios** — выбор вариантов, загрузка метрик, визуальное/числовое сравнение.
5. **ExportResults** — если экспорт войдёт в объём функциональной модели.

## Swimlanes

**[LENDING]** Activity Diagram используют `UMLSwimlaneView`.

Для urban-development дорожки следует назначать по ответственности, например:

- Пользователь;
- Frontend;
- Backend/API;
- Worker/Core.

Не делать дорожку для каждого технического класса.

## Statechart

Подходящие объекты:

- Run: created → queued → running → completed/failed/cancelled;
- Dataset: uploaded → validating → ready/invalid;
- Artifact/Result при наличии содержательного жизненного цикла.

Состояние должно быть устойчивым состоянием объекта, а не просто очередным шагом алгоритма.
