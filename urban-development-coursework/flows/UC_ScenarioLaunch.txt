ВАРИАНТ ИСПОЛЬЗОВАНИЯ «ЗАПУСТИТЬ СЦЕНАРИЙ РАЗВИТИЯ»

Действующие лица: Пользователь.
Цель: передать проверенный сценарий на выполнение и получить результат.
Предусловие: сценарий настроен и сохранён.
Постусловие: создан запуск; при успехе результаты доступны для анализа.

Основной поток:
1. Пользователь выбирает настроенный сценарий.
2. S1. Проверить конфигурацию сценария.
3. S2. Подтвердить запуск сценария.
4. S3. Выполнить генерацию сценария.
5. A1. При успешном выполнении завершить сценарий развития.
6. Система делает результат доступным для сравнения и экспорта.

S1. Проверить конфигурацию сценария:
1. Система повторно проверяет актуальность конфигурации и исходных данных.
2. При успехе разрешает запуск.

S2. Подтвердить запуск сценария:
1. Система показывает сводку параметров.
2. Пользователь подтверждает запуск.

S3. Выполнить генерацию сценария:
1. Система создаёт фоновую задачу.
2. Worker выполняет генерационный конвейер.
3. Состояние запуска сохраняется.

A1 [генерация завершена без критической ошибки]:
1. Выполняется «Завершить сценарий развития».
2. Система фиксирует успешное состояние и публикует результаты.

E1 [проверка конфигурации не пройдена]:
1. Запуск не создаётся.
2. Пользователь возвращается к настройке сценария.

E2 [пользователь не подтвердил запуск]:
1. Операция отменяется без создания фоновой задачи.
